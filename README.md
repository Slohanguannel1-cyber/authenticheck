# Authenticheck V1

Prototype SaaS Next.js pour l'analyse d'articles de seconde main.

## Lancer
1. `npm install`
2. `npm run dev`
3. Ouvrir http://localhost:3000

## À connecter avant production
- Authentification + base de données (ex. Supabase)
- Paiements récurrents (ex. Stripe)
- Modèle IA d'analyse d'images
- Stockage sécurisé des photos
- Génération PDF réelle
- Limites d'usage côté serveur
- Journalisation, modération et protections anti-abus

Le score actuel est une **simulation de démonstration**. Il ne doit pas être présenté comme une authentification réelle tant qu'un système d'analyse fiable n'est pas connecté.
